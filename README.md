# HiTeam

面向哈尔滨工业大学学生的竞赛组队与匹配记录平台。

## 运行方式

当前版本包含认证后端，不能只依赖静态页面运行。GitHub Pages 仅适合查看静态资源，登录、注册和业务数据需要同时启动本地后端，或部署到带 `/api/` 代理的服务器。

## 本地启动

在 Windows 上双击 `start-hiteam.cmd`，脚本会启动 Python 静态服务和 SQLite 后端，然后访问：

<http://127.0.0.1:8765/index.html>

## 已实现

- 四步任务向导：完善档案、找队伍、申请沟通、队长审核；匹配后由队伍自行建立群聊。
- 项目题目搜索联想，支持新增项目和已有项目选择。
- 年度项目、大创计划、竞赛关联和项目复用关系。
- 奖项简称、能力标签、简历预览和申请审核。
- 申请进度、联系方式释放、匹配完成后的队伍信息。
- 系统管理员、平台创建者和高级工具区。
- 浅色灰白主题、深色近黑主题和移动端布局。

## 说明

账号、档案、招募、申请、审核、消息、目录和草稿保存在后端 SQLite 数据库中；浏览器端只保存界面偏好、附件缓存和 JSON 备份。当前平台负责组队撮合和匹配记录，匹配完成后由队伍自行建立群聊。文件后端存储、HTTPS、服务端备份和生产级账号安全仍需继续完善。
