# HiTeam

面向哈尔滨工业大学学生的竞赛组队平台静态原型。

## 在线预览

GitHub Pages：<https://nuki019.github.io/hiteam/>

## 本地启动

直接打开 `index.html` 即可；需要完整浏览器环境时，双击 `start-hiteam.cmd`，或访问：

<http://127.0.0.1:8765/index.html>

## 已实现

- 五步任务向导：完善档案、找队伍、申请沟通、队长审核、匹配后协作。
- 项目题目搜索联想，支持新增项目和已有项目选择。
- 年度项目、大创计划、竞赛关联和项目复用关系。
- 奖项简称、能力标签、简历预览和申请审核。
- 申请进度、联系方式释放、匹配后协作清单。
- 系统管理员、平台创建者和高级工具区。
- 浅色灰白主题、深色近黑主题和移动端布局。

## 说明

这是纯静态本地原型，数据保存在当前浏览器的 `localStorage` 中。在线预览时，不同访问者不会共享申请、审核和消息数据；要做成真实多人平台，还需要后端、登录、数据库和文件存储。
